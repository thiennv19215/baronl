# Live2D assets

Không có model Live2D nguồn hoặc bằng chứng quyền sử dụng được cung cấp. Thư mục release không chứa model, texture, motion hay Cubism runtime asset từ ứng dụng cũ.

UI phải dùng `character-host-placeholder` cho tới khi chủ dự án cung cấp model hợp pháp. Khi thêm model, cần ghi rõ quyền đối với model, texture, motion, voice và runtime SDK; đăng ký từng file cần ship trong manifest; không coi quyền dùng hình nhân vật là mặc nhiên bao gồm quyền phân phối model nguồn.
